## 消费者交接与失败恢复

复用入口是 `ops/bin/hf-dwd-research` 的 fetch → screen → publish 三阶段。
新任务先冻结 Git/HF/request/closure/环境身份及预算，再在合格节点建新 Job。
计算成功后直接进入 publish；遇网络失败，复用已完成的固定包进行有界上传重试。
旧 A4 Job 绑定旧提交且已有墙钟期限，复验从长期证据入口读取。

失败、缺失或 running 阶段回执停止发布。失败计算残留先保留隔离，定位原因后按原重试额度处理。
无 READY 的半包自动隔离恢复；有 READY 的损坏或冲突包保留并停止。
未来发现身份、阶段、预算或样本反例时，只重开受影响的 Worker 合同，保留原始结果和费用。
