## Publication boundary

The OCI `CURRENT` pointer was advanced atomically. Hermes candidates, raw shards, old revisions,
and its legacy `CURRENT` pointer were not changed. The weekly contract requires a new child
revision, parent lineage, and at least 90 calendar days of source re-scan before promotion.

The current PostgreSQL service has no `dwd` schema and OCI has only the deliberately read-only
`astock_ro` role. PostgreSQL therefore remains an unmaterialized, rebuildable serving projection;
this does not change the canonical file acceptance. Provisioning a least-privilege OCI publisher
over a private channel is tracked separately and must not be worked around with Hermes writes or
expanded read-only privileges.
