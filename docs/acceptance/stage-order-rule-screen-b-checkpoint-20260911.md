## 2. 已实现且不依赖新行情的部分

- **旧队列绑定**：以旧运行已接受manifest SHA锁住summary字节，再校验恰好512个代码
  的完整cohort_digest。仅有512这个数量、不同来源的同名文件或重写摘要均不能通过。
- **经济身份排除**：要求全部旧代码及006三代码均有身份映射；代码复用时排除所有对应
  经济身份，新代码映射至旧经济身份仍排除。新候选代码存在多义身份则不自动猜测。
  此组件只检查已提供映射的集合关系，不声称认证了外部映射完整性；输出明确false。
- **固定选择**：候选池按经济身份哈希取至多512；覆盖面板预分64个身份/季度槽位，
  缺失不换位，无效事实仍保留；挑战面板按48/32/16固定桶取不同身份，不跨桶补齐。
  对照实际观察的内容摘要锁住被选事实，输入顺序不影响选择。选择阶段不调用候选。
- **完整计分**：复用005封存与冷验证，再调用007唯一规则；NO_ASSERTION在明确正例上
  计漏报。参考未知不伪造成负例，另限其断言率。基准/两面板/四季度/面板季度矩阵均
  保留完整分母，另保留角色主分歧、共同未知和近期分歧。
- **失败优先级**：冲突或输入状态不一致优先BLOCKED_EVIDENCE；数量不足不补样；
  证据足够而表现不足则REVISE_TARGET_OR_PARK。组件的正面计算最高为
  PROMISING_EXPLORATORY_ONLY，不从角色或external_ai字符串自动升级独立验证。

评分入口只读取既有不可变参考包。其输出为SCORING_COMPONENT_ONLY，不是最终研究
结案；source_isolation_verified和runtime_activation_authorized仍为false。源资格、
意见可见性、实际封存次序及执行准入仍需运行适配器提供真实证据。本轮没有新建另一套
参考协议、行情指标、永久ADM、分类器或Worker路由。
