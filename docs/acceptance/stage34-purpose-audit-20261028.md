## A1 / P2 — Define the daily opportunity set and scoring unit before claiming list value

The use contract specifies K=5 and identical context input, but does not freeze a full per-day
opportunity set, the handling of repeated episodes and20/60-scale alerts, or whether one review
slot refers to a security or a context. A one-context-per-episode stratified quality sample does
not by itself represent a daily list. This is a future evaluation-design gap, not an observed
failure of a comparison that was never run.

Independent metadata census of the retained318 contexts found132 distinct dates;114 dates have
fewer than5 contexts,9 have exactly5, and only9 exceed5. There are11 repeated security/date groups.
Thus K=5 would be nonbinding on123/132 dates of this old sampled pool. These counts diagnose the
old pool; they do not predict the new245-issuer population.

Before execution, define a fixed eligible security/date or context/date universe and explain which
actual review action the slot purchases. Retain all UNKNOWN cases in that universe. Freeze the
positive/error meanings, including a wrong3-versus4 assertion, an ambiguous assertion and a missed
eligible case. Equal maximum budget is not automatically equal actual usage: report selected and
unused slots and the cost actually used by each arm; do not manufacture alerts to fill quotas.
Keep recognition sampling and use-list evaluation as distinct consumers of shared immutable Facts.

## A2 / P2 — A requirement for independent reference is not an implemented reference route

The purpose contract correctly rejects the deterministic persona panel as independent semantic
truth, but no new reviewer/rubric/evidence-tier/adjudication route has been exercised. More market
data will not repair that missing route. Calling another process or adding persona names cannot
create semantic independence. Conversely, unavailable source receipts do not demonstrate that
new acquisition is the first necessary expense.

First test a candidate-blind, separately attributable research-reference procedure on a small,
frozen set of already consumed development packets. Use T-only neutral facts, keep old labels,
sampling-stratum names and candidate outputs hidden, require cited facts and allow unresolved
disagreement/UNKNOWN. Describe AI-assisted judgments at their actual evidence grade; agreement
between models is not human validation or proof of market truth. The pilot tests the method and
its cost, and cannot refresh the old pool into formal test evidence.

Only after that route is viable should a bounded P10 task qualify new input from the exact245
identity route, reusing existing sources before requesting new acquisition. Keep old #566 closed.
Freeze new identities, exposure rules, full histories and post-allocation capacity before new
references or scores;250 remains necessary, not sufficient. Do not label-select to make counts pass.
