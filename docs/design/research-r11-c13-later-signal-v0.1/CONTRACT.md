# C13 后续信号契约 v0.1

状态：**规则契约已起草，待信号与用途采用**。消费者为 P11 历史研究比较与 P12 日常候选解释。复核 023 在冻结源码上通过旧行为两项回归，确认当前无合格的同根后续信号生产者。契约和合成用例用于评审；当前账户、策略和原 T+1 继续使用现有版本。

**行为。** 首个合法开盘错过以后，可以对原机会显示观察原因。只有新日收盘时首次观察到「上一份合格评价明确为假、最新合格评价为真」的变化，且原因来自冻结后的后续信号规则，才能成为一次追加尝试的候选。已存在的 Trend 要求特征日期等于原事件的信号日；它仍服务原机会，后续新证据须由独立资格的生产者给出。资金释放、解除风控、价格刷新、同日更正、同一为真信号重传/持续，以及缺数后第一次变真，均停在观察。原来有真实成交的机会停在旧周期；清仓后再次买入按现行独立新 P4 事件以及 22/5 个交易日的原有边界。

| 身份 | 作用与约束 |
| --- | --- |
| 原机会 | 绑定原 P4 事件、输入快照和规则摘要，终态及窗口只读。历史汇总按这个键归因，原尝试和后续尝试可拆明细。 |
| 后续信号 | 绑定原机会、标的、规则和版本、先前与当前的证据身份；相邻日指权威日历的前一交易日，中间缺数据不得跳日补一份。两份有效评价使用同一规则版本，各自来源、证据时间、真实可用时间、决策截止可对账。相邻日是评审候选口径，直到日历规则采用前只做合成验证。 |
| 一次后续尝试 | 绑定账户、原机会、信号、拟采用规则和固定的下一合法开盘。该身份同时用于追加评估、专家决定与执行机会，原机会仍单独保存为归因键。它不会继承原尝试的周期、报单或回执。 |

**时钟。** 对每份独立评价，在同一指定时区校验 `evidence_at ≤ available_at ≤ cutoff`，并且证据日与特征日匹配。收盘后才可用的证据不能成为该日的信号，下一交易日重新取得当时合格的评价。候选开盘是决策后、同日历中登记的首个指定开盘；观察截止和开盘窗口由独立版本的政策显式提供，均不可顺延。首个原窗口应先实际关闭，即便原订单提前终止，也不能绕过原窗口。

**订单与并发。** 旧订单从未提交须有覆盖原窗口的事实证明；若曾提交，须明确终结、净累计零成交、费用及更正在同一时点完备对账。待成交、待确认、已成交（含部分成交）、未结费用、未处理更正、持仓或待结算均阻断新尝试。原成交迟到时走原流水，并在追加预约前重新读取；若追加预约已存在，按明确冲突保留双方流水与现有资金占用，停止新增并告警，不自行解锁或合成撤单。

同一账户和原机会只允许一个后续尝试槽，换政策版本也不重置；新尝试和预约必须在同一原子事务获准。预约未创建前，资金或资格不足可以更新观察；预约一旦成功，后续撤单或未成交不释放尝试槽。重复命令返回原 receipt，内容变化报冲突。已有专家、否决、同股唯一、现金、费用、桶和账户比例校验继续在后续预约前兑现。观察、合格候选、预约和真实成交必须保留各自状态。

**实现面。** 保留现有 `project_candidate`、已封存窗口和原专家入口。单一新评估入口接收父机会、成对信号证据、已认领的政策/日历及当时完整账户事实；只输出观察、阻断、候选或原回执，不代替账户层。现有 `decide_entry` 要求专家事件 ID 与执行机会匹配，且由机会 ID 派生周期，因此候选方案使用独立后续尝试作为执行机会；P12 同一事务持有一条到父机会的不可变映射。具体适配仍须合成证据验证，不能靠重写已过期记录实现。

**一个可验证的信号候选。** 复用 `classify_trend_stability` 的原判据，测试前一交易日明确 `neutral/fragile`、当日 `stable` 的状态变化；`None` 单列为未知。该纯分类函数可用作候选原料。新生产者还须把两个真实可用时点、来源、父机会和当日专家/风险资格绑定，另行证明这条变化适合解释为新增买点。该候选不引入新的数字阈值，也不迁移旧 Trend 事件评估的资格。

**待采用字段。** 合格生产者及布尔条件、观察有效期、交易日历和连续评价计数口径、执行窗口、一次零成交重试许可都须绑定确切版本与证据。当前机器契约以 `null` 表示这些缺项；观察可以设计，交易候选不准入。P10 #701 仍为原窗口和 PIT 供给所有者。历史增量比较在独立资格之后才启动，固定现金、费用与退出，保留原 T+1 对照，报告新信号数、候选提升、成交率、费用、净收益和回撤。
