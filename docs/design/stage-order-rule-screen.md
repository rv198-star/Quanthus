## 2. 已解决的业务边界

1. **低效率与下跌不互斥。** 有方向的生命周期与窗口内路径效率是不同维度。参考评价
   当前20会话的失稳证据，不以“能讲成一段下跌故事”直接否定0，也不以跌幅大直接确认0。
2. **中心迁移有参照。** 比较当前20会话与紧邻前20会话的范围中心；新位置上的窄箱体
   不自动等于原位置稳定。是否需要“迁移后已稳定”的时序阶段不在本版悄悄增加。
3. **整理是窗口描述，不是延续承诺。** 当日T包括在描述窗口。若末日跳变但整个窗口仍
   满足窄命题，可以保留整体整理与近期风险并存；不据此推导突破、买点或安全持有。
   要判断先前箱体被破坏，需要固定旧锚点/过程，属于不同问题，不能偷偷混入本版。
4. **没有确认不等于两者皆非。** 机器未命中阈值输出NO_ASSERTION；只有外部参考双方
   明确否定两命题才记NEITHER。输入不可用、参考UNKNOWN、分歧、规则冲突分别保留。
5. **近期变化不改目标。** 10日宽度和中心事实照原样保留；不增加“10日也必须收缩”的
   隐含条件，也不抹掉与主窗口不同的近期证据。

这些取舍是本站的可证伪研究定义，不是宣布市场中的“无序”只有一种正确含义。旧006
参考维持原样，不能通过重新解释本章把旧分歧补发为一致。

## 6. 验收：不能以少数命中或全不回答过关

先查证据完整、来源隔离、参考无候选泄漏、原意见不可改及分母一致。不满足为技术/证据
阻断，不能报告业务PASS。同源模拟必须保留其低证据等级。

两面板分别报告完整混淆表：参考0/2/NEITHER/AMBIGUOUS/INPUT_UNAVAILABLE，候选0/2/
NO_ASSERTION/INPUT_UNAVAILABLE/RULE_CONFLICT。NO_ASSERTION在正参考上计漏报，不能
删除不回答的案例来抬高precision。参考AMBIGUOUS不作错误标签强算准确率，而单列断言率。

本站是有界开发筛查，数值是投入决策门槛，不是统计证明或旧004资格门槛的替代：
- 完整参考>=120例；每类明确正例>=20、明确负例>=20；两类预测各>=20；
- 开发面板benchmark中两类分别precision>=0.80、正例覆盖>=0.55、明确负例误报<=0.10；
- 模糊参考>=10例时，其候选断言率<=0.20；不足则不作歧义性能已验证主张，整体证据不足；
- 同尺度候选冲突=0；两个面板和四季度分母、角色一致/未知/分歧全部披露；
- 覆盖面板每类有>=10个明确预测时，precision<0.65构成否决，不允许挑战富集掩盖。

benchmark合并数字只描述这个固定混合面板，同时必须给出分面板值；不是市场precision，
不套独立同分布假设宣称95%置信或概率。分季度结果用于发现共同事件驱动，样本不足
明确写出，不能宣称跨环境稳定。80%等门槛是本次预设筛查目标；旧004的Wilson/F1和
其他门槛继续保留在旧合同，不在本站补发资格。

处置优先级：证据/协议失败 -> BLOCKED_EVIDENCE；参考/预测/歧义数量不足 ->
INCONCLUSIVE_NO_SUPPLEMENT；证据足够但任一表现门槛不满足 -> REVISE_TARGET_OR_PARK；
全部满足且仅相关模拟来源 -> PROMISING_EXPLORATORY_ONLY；全部满足且另有真实来源与
隔离证据 -> READY_FOR_BROADER_VALIDATION。最后两者都不是正式标签或交易资格。

同一批不二次调参、不扩样。D按错误类型分为目标歧义、参考不足、表示不足、规则问题、
来源问题；可以形成一次明确的后继建议，但不得自动重试直到通过。0/2任一方向不足都
不能把父里程碑写成完整可靠识别已完成；各方向证据仍单列，不抹掉已得结果。
