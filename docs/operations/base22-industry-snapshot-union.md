# Retained industry snapshot union

This bounded scope preserves the original 5,201 native memberships and adds only
source-declared August snapshots. Each source company resolves through exact dated
security identifiers; node code, name and classification must match. The provider
update date is retained in raw evidence and never substituted for the snapshot
date. Acquisition and the original dated parent knowledge floor are preserved.
These are static snapshots, not inferred historical PIT industry facts.

The same immutable seven-table native dependency supplies all four weekly adapters,
including the venue parent of security identifiers.
The output carries independent physical files, every selected manifest/READY/raw
source, the original membership and full input/code/configuration identities.
Offline verification reconstructs all snapshots from the local raw files, compares
every native and projected typed atom, then checks whole-scope keys, references,
cutoff and lineage. Duplicate business/version keys and unknown source/date/node
identities fail closed. No native row is replaced or relabeled.

The exact 50 historical governance exceptions, BSE and ended-listing boundaries
remain separately governed. Passing this scoped union does not close those PIT
questions or qualify unselected sources, the complete August universe, consumers
or a complete Base 2.2. No CURRENT or image READY is written.
