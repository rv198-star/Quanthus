## 摘要

原文设计一个 A 股公告与新闻舆情专家，原则是先守后攻：对空仓候选的生存级风险一票否决（`BLOCK_NEW`），按产业链顺逆风压低仓位上限，利好催化默认弃权，只在强信号时参与共振。持仓一律不动，退出继续服从既有四源仲裁。

结构分三段：DAG-1 先用 Python 做硬规则排雷、金额占比分档和近 7 日去重，再交判别模型输出 5 个维度的概率；DAG-2 把舆情记忆与近期量价形态交叉校准；DAG-3 做产业链聚合，并用隔夜外盘锚点的完整开高低收识别“高开回落诱多”。结果通过 `expert_protocols.py` 的否决、约束、打分三类专家接入 `aggregator.py`。

分三期推进：Phase 1 只用现有盘后数据离线回放；Phase 2 依赖 P10 新增夜间和盘前采集，做 06:30 与 09:10 两个盘前截点；Phase 3 分级准入，依次为影子运行、只否决、否决加共振。验收分四层：PIT 与零漂移、金标语义准确率、净避险价值与活跃子集收益、44–66 个交易日前瞻影子。

## Owner 决定（2026-11-24）

1. 判别模型以 Gemini Decision 为主。Jev 中文偏弱不作为阻断项；alpha 接口有风险，影响有限。
2. 舆情与新闻由 P10 从 2026-11-24 起扩展前向采集。Base 2.6（#615，11-30 截止）不含任何舆情新闻数据；Base 2.7 起收录 2026-12-01 以后的数据；11-24 至 11-30 的数据作为试运行和测试样本，单独保留身份。
3. 2026-11-25 结束后，为英伟达 / 黄仁勋案例采集专案样本，用于基本测试。
4. 第二阶段在模拟盘中逐步完善、积累可信度；前向采集的完整 PIT 数据以后可以反复复盘。与现行分工和时间规则的冲突，通过协商重订解决。
5. 当前推荐操作（P12 D1-B）不按 System 1/2 改造。
6. 英伟达 / 黄仁勋专案中 A 股的走势作为以后策略训练的验证集，用途仅限验证。定义已在 A 股 11-24 开盘前冻结（#737）。检索窗口为美东时间 11-05 00:00 至 11-25 16:00，北京时间 11-26 06:30 出包（#736）。
7. P11 处理舆情专家研究和这个专案，前提是 P12 D1-B 推荐操作已上线并通过验收（#724）。在此之前，P11 的重心仍是推荐操作。研究候选登记为 #739；P10 的采集（#735、#736）独立进行。

## 对 Quanthus 的适用性

**System 1/2 与 DAG。** Quanthus 现有结构已经与之对应：P11 研发相当于 System 2，离线编写并验证规则；P12 每日运行执行确定性流程。判别模型只作为新节点，处理代码算不出来的判断，主要是文本。在“只拦不买”的用法下，模型误判的后果是少买一笔，或没拦住原策略本来就会做的交易，所以精度决定价值，不影响安全。进入利好加分后，模型判断会直接促成买入，精度重新成为安全问题。

**模型节点规矩**（首个模型节点接入时适用）：

1. 模型只放在 P11 专家内部，输出离散选项和概率，由代码映射为否决、约束或打分；不直接产生订单或股数。
2. 问题说明和判断标准由 System 2 离线编写，带版本和摘要，随规则一起交付。
3. 模型在每日运行任务内调用。请求摘要、模型快照、原始响应和响应摘要封存进评估回执与来源闭包（见 #719 运行接缝）；重放只读封存结果，不联网。
4. 超时或不可用时按专家声明处理：否决类对空仓候选禁止新开，催化类弃权，持仓一律不动。
5. 运行侧另需 API 密钥、CN02 访问 OpenRouter 的出网路由，以及晚间出包窗口内的耗时与费用预算。

**需要重订的两处。**

- 运行归属：原文写 P11 每天 06:30 和 09:10 计算。按 2026-11-24 冻结的分工，P11 交付固定规则版本，每日运行由运行时任务执行。
- 时间规则：在事先配置的决策截止（例如 22:30）前发布的盘后公告，适用现行 `close-to-next-open-v1`，可作为 P11 规则内的专家接入。06:30 和 09:10 的盘前信息需要新的版本化盘前规则，以及 P12 的盘前限制合同：只追加记录，只限制尚未确认的买入计划，不动持仓。原文的 Level 2 联合打分依赖这套新的盘前规则。

**验收。** 第三层“叠加到基线策略回放”需要合格的历史策略回放，而 R11 的 U06 历史比较目前因数据受限停放（#701）。可先用现有 P4 事件库做逐事件反事实，主要证据来自前向影子运行。历史公告只有日期级时间，按次日可见处理，因此历史测试会低估实时效果。金标样本由谁标注要先确定；模型标注的结果不能作为独立金标。
