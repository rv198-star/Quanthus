# P3-STAGE-019 — Third-Group Portfolio Rebaseline Review

Design status: approved  
Delivery gate: accepted governance checkpoint

## 1. Why this review exists

P004 through P018 were opened as a bounded `0/2` sub-route after P3-STAGE-003 decomposed the third group into `0/2`, `1/12`, and `8/9`. The local work was valid, but the sequence gradually concentrated almost entirely on Stage-0 structural-instability qualification. The governing historical-learning design explicitly allows a subgroup to be retained, renamed, demoted, or parked and forbids forcing all labels to pass.

This review therefore asks a portfolio question rather than another Stage-0 question: has the `0/2` branch produced enough evidence to decide its disposition and return to the remaining third-group work?

No preserved partition is opened by this review.

## 3. Same-origin four-party review

The following are same-origin simulated roles, not independent human experts.

### Short-term trader

The useful finding from the Stage-0 work is not a better universal threshold. Expansion disorder looks like a real observable pattern, but broad two-way action mixes too many market situations. Continuing to optimize the umbrella Stage-0 label would delay learning the rest of the lifecycle. Park the parent qualification and move on.

### Fund manager

The Stage system is supposed to organize different structural contexts, not maximize one classifier. Stage 2/orderly consolidation remains useful as a descriptive proposition, but it should not be promoted merely because Stage 0 is parked. The next missing portfolio component is downside lifecycle `12 -> 1`, where the accepted Trend Evolution Facts already provide an appropriate substrate.

### Quant

Two materially different scale treatments both produced 0/9 eligible Stage-0 profiles. P018 attributes the main error to proposition composition rather than a missing numeric tweak. A fresh child-mechanism study could be scientifically valid, but it is not the highest-value next experiment for the program. The correct experiment budget decision is to park Stage-0 qualification and allocate the next bounded development slot to `1/12`.

### Data governance

P018's fresh-mechanism recommendation must remain in the record; it should not be rewritten after the fact. P019 may supersede it as the active route because P019 is a higher-level portfolio decision made before any P019 result-bearing run. Stage 0, Stage 2, expansion child, and broad child must keep distinct dispositions and authority ceilings.
