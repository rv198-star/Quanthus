## 1. Decision context

P032 closed the bounded historical strict-PIT source-evidence search. The next decision therefore
returns to product value rather than extending source archaeology.

Two accepted facts constrain the route:

1. `P3-STRUCT-002` closed with lifecycle disposition `prefer_continuous_structure_facts`. In its
   frozen complete-P2 development comparison, coarse compression of the same structural
   information had lower return and higher maximum drawdown than the continuous representation.
   That result is development evidence only, but it means a Stage layer must not replace Continuous
   Facts merely because it is easier to name.
2. P029 showed that the Layered Stage Proposition Bundle has a narrower, real-history semantic
   advantage over forced Top-1 representation: on the exact ten accepted retrospective Stage10
   observations, layered output retained all 16 explicit parent+nested propositions while the
   comparison single-code surface retained 10/16 and elided Stage10 parent context on all six
   Stage10+11 rows. P029 did not establish utility over Facts-only.

The unresolved value question is therefore not whether a coarse state can replace Facts and not
whether Stage predicts returns. It is whether a **layered semantic overlay on top of the same Facts**
measurably improves consumer interpretation quality or review cost.

## 2. Role-separated review

The route was assessed from four bounded perspectives. This is a same-assistant, role-separated
review; the independent Astra CLI evaluator entry was unavailable at route-review time because its
runtime did not inherit the required authentication environment. No external independent opinion is
claimed here.

### Short-term / event-driven

A layered `structural failure + nested rebound` overlay may prevent a consumer from mistaking a
rebound for a resolved break, but only if it reduces actual interpretation errors relative to the
same continuous Facts. A prospective shadow is premature until that incremental comprehension value
is shown.

### Fund / portfolio risk

Continuous Facts should remain the evidence substrate. A semantic overlay earns a place only if it
improves communication consistency around persistent risk context and nested recovery conditions.
The lowest-cost next question is therefore a blinded interpretation comparison, not another market
or strategy experiment.

### Quant research

P3-STRUCT-002 already supplies a strong baseline discipline: Facts-only must be retained. P029's
16/16 result is representational, not statistical utility. The next experiment should compare
identical observations and identical Stage definitions, changing only whether the precomputed
layered overlay is shown. Metrics must be preregistered and must not include return or prediction.

### Data / methodology

Consumer utility can be tested entirely from existing immutable P029/F9 evidence, preserving the
closed PIT boundary. This avoids new source authority, new market reads and future waiting. A
prospective auditable shadow remains a possible later route only if the overlay first shows enough
consumer value to justify collecting additional operational evidence.

## 3. Selected route

P033 selects exactly one question:

> On the exact frozen P029 population, with identical underlying Continuous Facts and identical
> Stage10/11 semantic definitions, does adding the validated Layered Stage10/11 overlay reduce
> interpretation error, inconsistency or review cost relative to Facts-only?

The experiment is **not** permitted to ask whether Stage predicts returns, improves trading, beats a
strategy baseline, or recovers strict historical PIT.

## 4. Why the other routes are not selected now

### Prospective auditable shadow

Collecting clean forward receipts is methodologically attractive, but it creates ongoing data and
operational cost before the Stage overlay has demonstrated incremental consumer value. It remains a
future option, not part of P033.

### Stop Stage-specific work now

Stopping remains a legitimate outcome if P033 shows no useful consumer increment. It is premature
before testing the one value proposition that P029 left open: semantic organization on top of Facts.

## 5. Change-control triggers

A fresh four-party review is required before continuing if implementation would require any of:

- a different market-data source or knowledge-time claim;
- changing the exact P029 population;
- tuning Stage10/11 thresholds or parent semantics;
- replacing Facts-only with a weaker baseline;
- using future returns, P2 economics, strategy output or protected partitions as an evaluation target;
- expanding the experiment into prospective shadow collection;
- changing the preregistered primary interpretation metrics after evaluator results are visible.

## 6. Claim ceiling

A positive P033 result can support only this statement: for this bounded development population and
frozen consumer task, the Layered Stage10/11 overlay improved measured interpretation utility over
Facts-only while preserving the Facts substrate.

It cannot establish prediction, economic value, out-of-sample generalization, strict PIT,
production-expert authority, strategy authority or trading authority.
