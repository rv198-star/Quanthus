## New isolated data-product release topology

`src/quanthus/pipelines/loss_aware_m1_publication.py` copies each original source gzip response and the SHA-bound per-security quality status into a distinct ODS evidence package. It separately copies a verified research-only DWD package with an immutable manifest, canonical file inventory and actual source-observed 1m rows only.

- `SOURCE_EVIDENCE_READY` means the 4,992 supplier response files are physically retained and SHA-checked, **not** that every single security passed research qualification.
- `READY` on the DWD means **R0/R1 data qualify for the named restricted research consumer** at >=99% traded-universe and >=98% each exchange/board cohort; suspended statuses are separate.
- `NOT_READY` on the 10/08 DWD is honest partial coverage and prohibits promotion into the research consumer.
- `date-status/<date>.json` reports *every* assessed date, including NOT_READY. `CURRENT_RESEARCH_1M.json` advances only through research-ready dates. It is never `CURRENT.json`, `CURRENT_DAILY_CORE.json` or the old intraday 1m full four-lane pointer.
- This publication is opt-in; it never flips legacy timers, sends to OCI automatically, declares source timing equivalence or grants downstream trading authority.
