## Entry and archive verification repairs

`preflight_role` checks canonical physical work/root/TMP paths, both directions
of source/output overlap, other-role separation, deadline, device and free-space
reservation before any role write. It is shared by the controller and CLI;
ongoing RSS/spill/time enforcement remains in the bounded controller.

Immediate acceptance still proves selected inputs did not change after the role
hashed them. Durable `review_control_archive` instead requires an externally
pinned acceptance anchor, verifies frozen identity and every archived byte,
recomputes graphs and accounting, and never dereferences historical source or
code paths. Explicit relocated role roots do not rewrite original provenance.
It does not claim the historical inputs are still present or currently unchanged.

CLI for old TC/TH archives:

```bash
python -m quanthus.expert_strategy.p3_historical_controls \
  --freeze /absolute/freeze.json \
  --archive-anchor /absolute/accepted-anchor.json \
  --anchor-sha256 sha256:EXTERNALLY_TRUSTED_DIGEST
```

Optional `--archive-roots` supplies the two relocated role directories. Never
derive the trusted digest from an untrusted archive merely to make it pass.

## Complete comparison and disposition

Returns below are cumulative 2012–2021 net returns on the original 500,000
capital, not annualized returns or exposure-matched alpha. All ten calendar
years and five fixed two-year periods are retained in `BH-analysis.safe.json`
and independently checked in `BH-periods.safe.json` in the evidence root.

| Arm | Net return | Maximum drawdown | Average exposure | Fees |
| --- | ---: | ---: | ---: | ---: |
| B | 52.19% | 12.58% | 18.42% | 17,486.28 |
| T | 7.97% | 18.72% | 21.39% | 10,777.92 |
| TH | 28.60% | 6.32% | 10.15% | 10,359.78 |
| BH | 27.51% | 8.23% | 10.34% | 17,307.79 |

BH−B sacrifices 24.676024 return percentage points for a 4.353176-point
drawdown reduction, with materially lower exposure. BH's net return exceeds B
in only 2/10 calendar years and 1/5 two-year periods. The existing one-point
research screen is not satisfied. Its descriptive paired-block intervals cross
zero for both return and drawdown; this is not a statistically established
universal harm or protection claim.

TH−BH adds 1.085884 return points and reduces drawdown by 1.904025 points,
but both descriptive intervals cross zero and TH exceeds BH's return in only
3/10 years. H has a drawdown-protection observation without Trend, but these
results do not establish that protection requires Trend or that Trend has a
reliable incremental benefit when H is retained. The return interaction
`(TH−T)−(BH−B)` is +45.304796 points; the drawdown interaction is −8.044558
points. These are differences between fixed portfolio paths, not a general
causal or future-performance claim.

The prior, explicitly post-hoc 50% B / 50% cash analytical reference returns
26.09% with 7.22% drawdown and 10.09% average exposure. BH adds only 1.42 return
points while its drawdown is 1.01 points worse. That reference did not replay
lots or fees at reduced capital and is not an executable comparator. It supports
retaining exposure attribution as unresolved, not declaring H disproved.

**Bounded closeout:** do not promote current H as a universal improvement or
current Trend as a required component. Stop further micro-tuning of this
version; keep simple B as the common research reference and preserve TH as an
unqualified risk/return tradeoff observation. The low-capital ambiguity trigger
is observed, but the frozen request and job authority retain that cell as a
proposal. It was not executed or relabelled as accepted. A negative/inconclusive
research outcome completes these three main steps; resolving every subsequent

If a later low-risk product decision warrants continuing, the only proposed
