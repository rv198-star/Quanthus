# R2：得到一条值得进入资金回放的动量候选

本批的实际改变是：将原有 **20日未复权动量 [2%,12%]** 从“已有筛选条件”推进为
**有证据支持、可优先进入下一笔带费用资金回放的候选**。决定分支为 `advance / supported`。
计算、独立重建和作者自审均已完成，未追加参数搜索或市场计算。

| 核心问题 | 本批结果 |
| --- | --- |
| 保持其他原筛选相同，动量区间提供多少增量？ | 次日开盘至收盘价格响应，候选相对互斥区间外对照平均 **6.4101bp** |
| 两年是否同向？ | 2020年 **6.5976bp**；2021年 **6.2498bp** |
| 不确定性与事前门槛 | 20交易日循环移动块、按年分层2000次；95%区间 **[2.1334,10.5830]bp**；满足平均≥5bp、两年为正、区间下界>0 |
| 比较覆盖多少样本？ | 449个配对日（2020/2021：207/242）；候选90,573机会/2,868 listing，对照256,037机会/3,396 listing |
| 是否依靠少数证券？ | 最大单listing占比：候选0.1943%、对照0.1617%；前10占比1.7080%/1.4549%，均通过冻结门槛 |
| 独立核对 | pandas/numpy重新构建身份、交易日、特征与分组，整数及分支一致；最大浮点差 2.78e-17 |

范围为2020–2021已消费开发窗的回顾研究。标签是次日盘中价格响应；后继经济评价采用
A股T+1持仓规则、费用、滑点、退出和资金曲线。研究线目前到了“有一个应优先回放的具体候选”阶段。
