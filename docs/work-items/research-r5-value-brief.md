# R5：跨夜后保留约85%的盘中价格差异，保留分布级证据

本批解决了一个具体未知：R2固定动量组相对对照组的盘中价格差异，是否会被隔夜抵消？
在同一共同样本上，跨两次开盘的平均差异为 **5.4078bp**，约为盘中差异的 **85%**。
按事前规则，现已落实“保留这条分布级研究证据”的资源决定；本批到此收口，
下一笔投入先明确会使用这条信息改变动作的具体消费者。R4固定持仓用途继续停放。

| 本批取得的结果 | 实际含义 |
| --- | --- |
| 两开盘差异5.4078bp；95%区间[0.7661,10.0647]bp | 达到事前全窗≥5bp、两年均为正、区间下界>0的保留门槛 |
| 2020/2021分别5.9463/4.9453bp；448个配对日 | 结果来自已消费的2020–2021开发窗与固定未复权价格总体；年度门槛为正值 |
| 共同样本盘中6.3645bp、隔夜−0.9993bp、交叉项0.0426bp | 隔夜抵消约1bp，保留了大部分盘中差异；三个分量使用完全相同的人口和时钟 |
| 一次正式、一次独立构建；32,442节点对齐 | 日历连接、样本、逐年分母、价格分解和最终分支均通过独立验收 |

此前项目已有盘中总体统计和R4资金比较，现在增加了两者之间的价格时钟证据。
本批用途是筛选资源分配；资金消费者仍需独立处理费用、公司行动和可执行卖出资格。
本批没有新增Worker，复用了原56成员输入和现有环境。

投入取得了原定信息增量，价值集中在减少下一步选题的不确定性。正式/独立计算分别
64.27/62.49秒，输入网络下载0B；原完整Linux检查877.43秒、专项17.86秒。
主要成本在设计、独立审阅、守卫修复和交付，完整主动工时、Token与账单为
`unknown_not_zero`，R1/R2/R4及本批失败和旧窗口曝光持续累计。原回传连接超时
180.20秒；恢复既有凭据/代理后的独立传输49.01秒，累计使用两次发布机会。
